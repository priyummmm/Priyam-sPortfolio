# Priyam Singh — Portfolio

My personal portfolio website — built from scratch with HTML, CSS, and vanilla JavaScript. No frameworks, no templates: just a hand-coded, responsive site to showcase who I am, what I've built, and what I'm learning.

**🔗 Live site:** _add your deployed link here (GitHub Pages / Netlify / Vercel)_

## About

I'm a 3rd-year Computer Science & Engineering student at Dr. K.N. Modi University and a self-taught web developer based in Ghaziabad, India. This site is where I bring together my projects, technical skills, and background in one place.

## Built with

- **HTML5** — semantic structure
- **CSS3** — custom design system (no UI framework), CSS variables, responsive grid/flexbox layout
- **JavaScript (vanilla)** — scroll-reveal animations via `IntersectionObserver`, smooth-scroll navigation
- **Google Fonts** — Fraunces (display) + Space Grotesk (body)

## Features

- Fully responsive layout (desktop → tablet → mobile)
- Custom scroll-triggered reveal animations
- Sections for education, projects, technical skills, languages, and hobbies
- Clean, single-page structure with anchor navigation
